# zzap-easy 설치 파일

화면 아래에 동료들의 픽셀 캐릭터가 돌아다니고, 짧은 메시지와 투사체를 주고받는 사내용 데스크톱 메신저입니다.

**[최신 버전 내려받기 →](../../releases/latest)**

| 운영체제 | 받을 파일 |
|---|---|
| Windows 10·11 (64비트) | `zzap-easy_<버전>_x64-setup.exe` |
| macOS 13 이상 (Apple Silicon·Intel 공통) | `zzap-easy_<버전>_universal.dmg` |

설치 후 처음 실행하면 **초대 코드**를 묻습니다. 초대 코드는 방장에게 받으세요.

---

## Windows 설치

1. `zzap-easy_<버전>_x64-setup.exe`를 실행합니다.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 → **추가 정보** → **실행**
   (사내용이라 코드 서명을 하지 않아 뜨는 경고입니다.)
3. 백신 프로그램이 "클라우드 분석"을 묻는 경우가 있습니다. 회사 정책에 따라 선택하세요.
4. 설치가 끝나면 화면 오른쪽 아래 알림 영역에 새싹 아이콘이 생깁니다.

## macOS 설치

1. `zzap-easy_<버전>_universal.dmg`를 열고 **zzap-easy**를 **Applications** 폴더로 끌어다 놓습니다.
2. Applications에서 zzap-easy를 엽니다.
3. **"확인되지 않은 개발자"** 또는 **"손상되었기 때문에 열 수 없습니다"**가 뜨면:
   - **시스템 설정 → 개인정보 보호 및 보안** → 아래쪽 **"그래도 열기"**
   - 그래도 안 되면 터미널에서 아래를 실행한 뒤 다시 엽니다.
     ```bash
     xattr -dr com.apple.quarantine /Applications/zzap-easy.app
     ```
4. 키체인 접근을 물으면 **항상 허용**을 누르세요(로그인 정보 저장용).
5. 화면 맨 위 메뉴바에 새싹 아이콘이 생깁니다. Dock에는 나타나지 않습니다.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 메시지 보내기 | `Ctrl+Alt+Shift+M` (macOS `Ctrl+Option+Shift+M`) → 입력 → Enter (같은 단축키를 한 번 더 누르면 닫힘). 또는 내 캐릭터 클릭, 또는 대화 기록 창 아래 입력칸 |
| 투사체 던지기 | 다른 사람 캐릭터 더블클릭 → 지정한 투사체가 날아감. 던질 투사체는 트레이 아이콘 → 캐릭터·투사체… → 투사체 탭에서 지정 (기본 종이공). 0.5초에 한 번, 30초 안에 10번 맞으면 5초 기절 |
| 돌아다니는 범위 | 트레이 아이콘 → 설정 → 돌아다니는 구간: 짧게·중간·넓게 |
| 전체 주목 | 내 캐릭터를 3초 안에 10번 클릭 → 모두의 화면에서 내 캐릭터가 크게 커지며 "전체주목!!!!" (1분에 1번) |
| 말풍선 꾸미기 | 트레이 아이콘 → 설정 → 말풍선에서 스타일 선택 (같은 방 모두에게 보임) |
| 지난 대화 보기 | 트레이(메뉴바) 아이콘 → 대화 기록… |
| 캐릭터 바꾸기 | 트레이 아이콘 → 캐릭터·투사체… (ChatGPT로 만든 그림도 올릴 수 있음) |
| 잠시 숨기기·다시 보이기 | `Ctrl+Alt+Shift+H` (macOS `Ctrl+Option+Shift+H`), 또는 트레이 아이콘 → 캐릭터 숨기기 |

## 업데이트

새 버전이 나오면 트레이 메뉴 맨 위에 **업데이트 설치**가 나타납니다. 누르면 자동으로 받아 설치하고 다시 시작합니다.

## 문제가 생기면

트레이 아이콘 → 설정… → **진단 로그 내보내기** → 다운로드 폴더에 생긴 zip 파일을 담당자에게 보내 주세요.
(메시지 내용·초대 코드·로그인 정보는 들어 있지 않습니다.)
